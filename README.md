# Хвоя — концепт сайта для портфолио

Лендинг для вымышленного клиента: шесть деревянных будиночков в смерековом лесу возле Яремче (Карпаты). Сайт на украинском, под украинскую аудиторию. Это макет без функционала: форма бронирования и кнопки только для вида.

**Компания вымышлена.** Телефон, Telegram и отзывы — заглушки. В подвале замените `[Ваше ім’я]` на своё имя.

## Что внутри

- `index.html` — вся страница: первый экран с нарисованным пейзажем и формой бронирования, будиночки с ценами, календарь сезонов, чан, дорога, отзывы, FAQ и контакты.
- `css/style.css` — стили, адаптив до 360 px.
- Иллюстрации нарисованы на SVG прямо в разметке, без фото и внешних картинок.
- Шрифты из Google Fonts: Piazzolla (заголовки), Commissioner (текст), IBM Plex Mono (цифры и подписи). Все поддерживают украинскую кириллицу.

## Как посмотреть

Открыть `index.html` в браузере. Сборка не нужна.

## Как выложить на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → выбрать ветку и папку `/ (root)`. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

# Терикон — концепт интернет-магазина

Папка `terikon/`: стритвир-бренд из Кривого Рога с ограниченными дропами. Четыре страницы: главная с таймером дропа и лукбуком (`index.html`), каталог с фильтрами (`catalog.html`), карточка товара с остатками по размерам (`product.html`) и корзина с Новой Почтой и monobank (`cart.html`). Вещи нарисованы как технические эскизы в SVG, шрифты Dela Gothic One и IBM Plex. Бренд вымышлен.

После включения GitHub Pages открывается по адресу `https://<логин>.github.io/<репозиторий>/terikon/`.

# SushiMax — ребрендинг доставки суши

Папка `sushimax/`: концепт нового сайта для реального бизнеса SushiMax (Колин и Йиглава, Чехия). Стиль «премиум в чёрном и красном», логотип прежний. Меню, цены, адреса и фото взяты с sushimax.cz.

- `index.html` — сайт: выбор города при первом заходе, сеты с ценой за штуку, обеды Йиглавы, всё меню (608 позиций) с поиском и метками «Хит» и «Новинка», корзина с допродажей, предзаказ в нерабочее время, «повторить заказ», языки CZ, UA и EN. Заказ никуда не отправляется.
- `razbor.html` — разбор текущего сайта на русском: проблемы с цифрами, новый стиль, «было → стало», вопросы к владельцу.
- `higgsfield-prompts.md` — промпты для кадров первого экрана и блока доставки.
- `tools/photos.py` скачивает оригиналы фото из Poster и обрабатывает их, `tools/build_menu.py` собирает `js/menu-data.js` из API сайта и исправляет названия. Чтобы обновить меню: `python3 tools/photos.py && python3 tools/build_menu.py` из папки `sushimax/`.

Хиты в `js/app.js` (`HITS`) стоят для примера: настоящий список нужен от владельца. В подвале замените `[Ваше имя]`.

После включения GitHub Pages открывается по адресу `https://<логин>.github.io/<репозиторий>/sushimax/`.
